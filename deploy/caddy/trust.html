Trust this MonitorFlow server

No public certificate company vouches for the MonitorFlow server at @DOMAIN@, so it vouches for itself, with its own certificate authority (CA). Your device does not know that CA yet, which is why browsers show a warning. Do this once on each device and the warning goes away.

1. Download the certificate

Download the certificate

This file is public: it holds no password or secret. Your device will show it as Caddy Local Authority, the name of the web server MonitorFlow uses.

2. Check that it is the right one

Its fingerprint, a kind of checksum:

@FINGERPRINT@

The person who installed MonitorFlow saw a fingerprint at the end of the installation. The two must be identical. If they differ, stop here and tell them: this page may have been altered on its way to you. It arrived without encryption, so until you compare, you are only trusting your network.

3. Install it on this device

Windows, with Chrome or Edge
  1. Open the downloaded file and choose Install Certificate.
  2. Choose Current User, then Next.
  3. Choose Place all certificates in the following store, then Browse, and pick Trusted Root Certification Authorities.
  4. Choose Next, Finish, and Yes at the security warning.
macOS, with Safari or Chrome
  1. Open the downloaded file. Keychain Access opens and adds it; pick the login keychain if asked.
  2. In Keychain Access, double-click Caddy Local Authority.
  3. Open Trust, and set When using this certificate to Always Trust.
  4. Close the window and confirm with your password.
iPhone and iPad
  1. In Safari, tap the download button above, then Allow.
  2. Open Settings, tap Profile Downloaded, then Install.
  3. Go to Settings › General › About › Certificate Trust Settings and turn on Caddy Local Authority.
Android
  1. Tap the download button above.
  2. Open Settings and search for CA certificate.
  3. Choose Install anyway, then pick the downloaded file.
Linux, with Chrome or Chromium
  1. Open the browser's Settings › Privacy and security › Security › Manage certificates.
  2. Under the certificates you installed yourself, open Trusted Certificates (or Authorities) and choose Import.
  3. Pick the downloaded file and, if asked, tick Trust this certificate for identifying websites.
Firefox, on any system

Firefox keeps its own list, so do this even if you did the steps for your system.

  1. Click the download button above. Firefox asks whether to trust the certificate.
  2. Tick Trust this CA to identify websites, then OK.

4. Open MonitorFlow

Close and reopen your browser, then continue. There must be no warning this time.

Open MonitorFlow

Setting up a new server? Open the one-time setup link that the installer printed, to create the administrator. Otherwise, sign in as usual.

To be fully sure, click the padlock or the site settings icon next to the address, open the certificate details and select the top certificate of the chain. Its SHA-256 fingerprint must be the one the installer printed. Unlike this page, your browser cannot have been altered on the way.
